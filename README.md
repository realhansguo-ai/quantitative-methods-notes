# Quantitative Research Methods Notes
> 社会科学研究方法 · 定量研究系列笔记

## 📖 Introduction

本项目整理了社会科学研究方法课程中的定量研究相关学习笔记，旨在帮助对社会科学实证研究、计量方法和因果推断感兴趣的同学快速入门。

本仓库主要包含课程笔记、课后习题整理以及相关学习资料总结，希望能够帮助学习者理解定量研究的基本逻辑，并掌握社会科学研究中常用的数据分析方法。

本项目内容主要来源于本人在复旦大学相关课程学习过程中的课堂笔记整理，并进行个人总结与补充。

## 📚 Course Topics

本系列笔记主要覆盖以下内容：

### Part 1 · Regression Analysis

- 定量研究与定性研究
- 简单线性回归（OLS）
- 多元回归分析
- 统计推断
- t 检验与 F 检验
- 虚拟变量与交互项
- 回归模型中的实际问题
  - 内生性
  - 测量误差
  - 异方差性

### Part 2 · Causal Inference

- 因果推断基本框架
- 工具变量法（IV）
- 两阶段最小二乘法（2SLS）
- 断点回归设计（RDD）
- 面板数据模型
- 固定效应与随机效应
- 双重差分法（DID）

### Part 3 · Limited Dependent Variables

- Logistic Regression
- Multinomial Logistic Regression
- Ordered Logistic Regression
- 其他非线性模型简介

### Part 4 · Empirical Applications

- 学术论文中的计量方法应用
- 数据分析流程
- 回归结果解释
- Stata 与 AI 辅助研究工具使用
